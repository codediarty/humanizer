결제 · 토큰 자주 묻는 질문

토큰은 어떻게 쓰나요?

검사나 휴머나이징을 누르면 글자 수만큼 토큰이 빠집니다. AI 작성률 검사는 1,000자에 4토큰, AI 휴머나이징은 1,000자에 8토큰이고, 빠질 토큰은 누르기 전에 화면에 먼저 보여 드립니다.

결제하면 코드는 언제 오나요?

결제가 확인되면 보통 1분 안에 결제할 때 적은 이메일로 16자리 토큰 코드가 갑니다. 메일의 단추를 누르면 코드가 자동으로 들어가고, 결제하러 가기 전에 넣어 둔 글을 그대로 이어서 휴머나이징합니다. 메일이 안 보이면 스팸함도 확인해 주세요.

카드 명세서에는 무엇으로 찍히나요?

한국휴머나이저 운영사인 성균관컨설팅으로 표시됩니다. 결제는 성균관컨설팅 결제 페이지에서 회원가입 없이 카드 · 간편결제로 합니다.

남은 토큰은 사라지나요?

사라지지 않습니다. 충전한 날부터 5년 동안 쓸 수 있고, 같은 코드에 더 충전해 이어서 쓸 수 있습니다.

다른 기기에서도 쓸 수 있나요?

네. 메일로 받은 16자리 코드를 다른 기기에서 넣으면 남은 토큰을 그대로 씁니다. 코드를 아는 사람은 누구나 쓸 수 있으니 잘 보관해 주세요.
